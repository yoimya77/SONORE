# SONORE

https://github.com/user-attachments/assets/f6bfa1e2-0907-415f-b6f0-7b173cff73ff

決めた時間帯だけ、どのサイトでも動画の映像を隠して、音だけにする Chrome 拡張機能です。

## できること

- **映像だけを隠す**：遮断時間帯のあいだは、どのサイトでも動画の映像を隠します。音はそのまま流れます。
- **遮断時間帯**：時刻と曜日で決めます。いくつでも足せます。終了が開始より前なら翌日まで続き、開始と終了を同じにすると24時間になります。
- **例外指定サイト**：ここに書いたサイトでは、遮断時間帯の中でも映像を隠しません。サブドメインにも効きます。
- **一時解除**：どうしても見たいときは、申請して待つと、決めた時間だけ映像を表示できます。
- **設定の凍結**：遮断時間帯のあいだは、設定を変更できません。
- **状態の表示**：ツールバーのアイコンに、遮断中は「遮」、一時解除中は「解」と出ます。

## 入れ方

1. このリポジトリをダウンロードして、展開します（Code → Download ZIP）。
2. Chrome で `chrome://extensions` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押して、`manifest.json` が入っているフォルダを選びます。

入れた直後から、初期設定（毎日 0:00〜22:00）で映像を隠します。ツールバーのアイコンを押して「設定」を開き、遮断時間帯を決めて保存してください。最初に保存するまでは、遮断時間帯の中でも設定を変更できます。

## 使い方

### 一時解除

1. ツールバーのアイコンを押して、「一時解除を申請」を押します。
2. 待ち時間（初期設定は10分）が終わると、「承認されました」と出ます。
3. 承認から10分のうちに「〇分間 解除」を押すと、その時間だけ映像を表示できます（初期設定は30分）。早めに終えるときは「遮断を再開」を押します。

待ち時間と解除できる時間は、設定画面で変更できます。

### 設定の凍結

遮断時間帯のあいだは、設定画面に「設定凍結中」と出て、設定も例外も変更できません。変更したいときは、一時解除をしてから変更します。

### 例外指定サイト

設定画面の「例外指定サイト」に、1行に1つ書きます（例：`meet.google.com`）。設定を変更できるときは、ポップアップの「（サイト名）を例外にする」でも足せます。

## しくみ

遮断時間帯の中なら、ページに `video{display:none!important}` というスタイルを足すだけです。映像は見えなくなりますが、音は止めません。拡張機能をオフにしたり削除したりしたあとは、隠したままにしません。

隠すのは `<video>` 要素の映像です。ページの部品の中（Shadow DOM）にある `<video>` は、隠れないことがあります。

### 使う権限

| 権限 | 使い道 |
|---|---|
| すべてのサイトで動くスクリプト（`<all_urls>`） | どのサイトでも、映像を隠すスタイルを足すため |
| `storage` | 設定を、このブラウザの中に保存するため |
| `alarms` | 1分ごとに、アイコンの表示を新しくするため |
| `activeTab` | ポップアップに、今のサイトの名前を出すため（例外にするとき） |

入れるときに「すべてのサイトのデータを読み取り、変更できる」という意味の警告が出るのは、1行目の権限のためです。

### プライバシー

- 通信は一切しません。
- 設定は、このブラウザの中（`chrome.storage.local`）にだけ保存します。
- 書体も拡張機能の中に入れてあり、外から読み込みません。
- 見ているページの中身や、閲覧履歴は読みません。

## 開発

ビルドは要りません。ファイルを直したら、`chrome://extensions` で SONORE の再読み込みボタンを押します。

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の設定 |
| `content.js` | 各ページで、映像を隠すスタイルを足す |
| `background.js` | アイコンに状態（遮 / 解）を出す |
| `common.js` | どのファイルからも使う処理（時間帯の判定、設定の読み込みなど） |
| `popup.html`, `popup.js` | ポップアップ |
| `options.html`, `options.js` | 設定画面 |
| `dots.js` | 点の表示板に文字を描く。文字の形もここにある |
| `tips.js` | 説明の吹き出しを、Esc で閉じられるようにする |
| `style.css` | 見た目 |
| `fonts/` | 書体（画面で使う文字だけを切り出したもの） |
| `icons/` | アイコン |
